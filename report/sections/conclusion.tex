\section{Conclusion}

As already stated in the introduction, the goal of this project was to crate a system that can help users navigate through their environment by providing spatial guidance.
In this work we have shown a 3D spatial scene description system that leverages Gemini VLM to translate visual and depth information into a way to explain the environment to the user.
With the solution crated it is possible to get the location or height of objects, as well as further orientation assistance.

Returning to the original research question, we can conclude that the work in this field is still in its infancy and even throughout the time of working on this project there were multiple releases that changed our approach.
None of the models that are used in this project were available at the start of this research project.
This also shows that there is still work to do and that the field is still evolving with could potentially outdate this solution in the following months.
Still the results shown in the evaluation section reveal that it is possible to get accurate and consisted navigation and spatial guidance information by using the Gemini Pro Model and Gemini Live API.
On the other hand the resent launch of the Gemini 2.5 Pro model and the decrease in performance show that being dependent on closed source models can also come as a disadvantage.

\subsection{Future Work}

As shown in the discussion section, there are still limitations of the current solution hat can be fixed in the future.
The two most important ones are Model and Performance enhancements and System integration:

\begin{itemize}
    \item \textbf{Model and Performance Enhancements:} One aspect in order to improve the performance would be to further use example in- and outputs to get better json quality and results. 
    Additionally, adding ensembling techniques to the system could also help. 
    This means to use bach requests in order to get multiple results for the same input and then use a voting system to decide which result to pick. 
    Another idea would be to further use the confidence scores that are provided to filter out bad results.
    This could help to understand the quality of the segmentation and make better decisions based on that.
    \item \textbf{System Integration:} Another aspect that can be enhanced is the implementation of the system in a real world scenario. 
    This would include the integration of the application into a mobile app with would come with its own challenges. 
    For example, the system would need to use Websocket connections to the Gemini Live API in order to provide real time conversations.
    Another aspect would be to integrate voice to voice capabilities as of right now only text to text is implemented.
\end{itemize}
