\section{Introduction}
It is not always easy to navigate a city environment, especially for people with visual impairments.
Often times there are obstacles in the way that can be hard to detect, or there is no clear path to follow.
Using common navigation systems or apps that use 2D data or gps is not always sufficient to provide the necessary information for navigation.
Often times it is necessary to have a 3D understanding of the environment in order to navigate around safely.
This is where the idea of a 3D spatial scene description system comes into play.
The goal of this project is to create a system that can help users navigate through their environment by providing spatial guidance.
The app combines known VLM capabilities with 3D data to provide spatial information.
It should help the user by giving him information about the location, height and distance of objects around him.
There should also be a way of getting further navigation assistance by providing a way to ask questions about the environment.

\subsection{Research Question}
After analyzing the current state of the field and the above mentioned goals, the following research question was formulated:
\begin{quote}
\textit{How can a 3D spatial scene description 
system effectively translate visual and 
depth information into guidance to 
improve navigation of blind and visually 
impaired individuals.}
\end{quote}

\subsection{Structure of the Report}
At first the report will give an overview of the background and related work that is relevant to the project.
This includes software and algorithms that were discovered during the research phase and used further on.
After that a general overview over the concepts and the system architecture will be provided.
In order to evaluate the approach that is shown in the concept section, multiple tests were conducted.
These will be presented in the evaluation section and can give an idea of the performance and accuracy of the system.
Afterwards in the discussion section the report will focus on possible limitations that were found during the evaluation.
At last a conclusion with a summary of the project and a outlook on future work will be presented.
