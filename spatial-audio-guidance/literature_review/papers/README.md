# README for Literature Review Papers

This directory contains an overview of the papers reviewed as part of the literature review for the "3D Spatial Scene Understanding and Interactive Audio Guidance for Blind Users" project. 

## Purpose

The purpose of this literature review is to gather and synthesize existing research related to spatial scene understanding and audio guidance systems, particularly focusing on their applications for visually impaired users. 

## Structure

- Each paper reviewed will have a dedicated section summarizing its contributions, methodologies, and findings.
- The insights gained from these papers will inform the development and design of our application.

## Contribution

If you would like to contribute to this literature review, please follow these guidelines:

1. **Add a new paper summary**: Create a new markdown file in this directory with the title of the paper as the filename.
2. **Format**: Use the following structure for each paper:
   - **Title**: 
   - **Authors**: 
   - **Year**: 
   - **Summary**: 
   - **Key Findings**: 
   - **Relevance to Our Project**: 

By documenting and analyzing these papers, we aim to build a solid foundation for our project and ensure that our approach is informed by the latest research in the field.
